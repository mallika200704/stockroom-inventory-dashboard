# Stockroom — Inventory Intelligence Dashboard
Responsive JavaScript capstone with add/remove product, validation, automatic categories, search/filter, live metrics, category chart, formatted report, and CSV export.
## Run
Open `index.html` with VS Code Live Server. No backend or build tools required.
## GitHub Pages
Upload the files to a repository, then Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
